# Get currently configured OAuth app (deprecated)

**\[deprecated\]**

In light of the new
[`gargle::gargle_oauth_client()`](https://gargle.r-lib.org/reference/gargle_oauth_client_from_json.html)
constructor and class of the same name, `gs4_oauth_app()` is being
replaced by
[`gs4_oauth_client()`](https://googlesheets4.tidyverse.org/dev/reference/gs4_auth_configure.md).

## Usage

``` r
gs4_oauth_app()
```
