# Generate a random Sheet name

Generates a random name, suitable for a newly created Sheet, using
[`ids::adjective_animal()`](https://rdrr.io/pkg/ids/man/adjective_animal.html).

## Usage

``` r
gs4_random(n = 1)
```

## Arguments

- n:

  Number of names to generate.

## Value

A character vector.

## Examples

``` r
gs4_random()
#> [1] "bighearted-junco"
```
